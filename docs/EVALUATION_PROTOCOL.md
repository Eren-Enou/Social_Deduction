# Evaluation protocol

Run `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, and `cargo test`. Run `cargo run -- evaluate evidence/experiment-001.json` once for frozen evidence; CLI refuses to overwrite existing files. Record actual counts and replay outcomes in FINDINGS_001.md. Preserve null and mistaken results. Baselines are specified before the evaluation seeds are run and are not tuned to outcomes.

Evidence includes full input/action/effect reports for every run, versioned configurations, and summary counts. No successful social-behavior inference follows from these fixtures. Future changes require a new version and evidence filename.

For 002, first specify mechanisms, hypotheses, controls, and seed fixtures in experiments/002/specification.md. Run `cargo run --bin experiment002 -- evaluate evidence/experiment-002.json` to freeze evidence once. Repeat evaluations use a new output filename; never overwrite either experiment's frozen files. The full test suite verifies the original 001 CLI evaluation byte-for-byte and all frozen individual reports, as well as frozen 002 evaluation. Analyze selected communication, sincerity, intent support, matched input differences, and unchanged ballots separately from verdicts. Report actual null results in experiments/002/results.md.

For 003, preregister listener/judgment rules, fixture family, confounding controls and metrics in experiments/003/specification.md. Primary command: `cargo run --bin experiment003 -- evaluate evidence/experiment-003.json` (create once only). The full suite compares all historical artifacts and the new frozen evaluation without overwriting them. Counterfactuals measure candidate, score/margin, actual vote and verdict changes separately; scored support is not calibrated confidence. Audit selected versus injected testimony origins. Preserve equal-visible-input/different-hidden-intention controls and unsuccessful influence. Record scientific findings in results.md and engineering validation separately in validation.md. New hypotheses after evaluation require new preregistration and evidence; do not retrospectively tune the primary algorithm.

For 004, preregister provenance assumptions, relay selection, recipient scopes, weights, depth limits, fixtures, seeds and metrics in experiments/004/specification.md. Run formatting, warnings-denied Clippy and the full test suite before freezing with `cargo run --bin experiment004 -- evaluate evidence/experiment-004.json`. The CLI uses create-new; repeats require a new filename. Add and run a full frozen-report regression afterward without altering the primary algorithm. Preserve historical artifact hashes and replay contracts.

Compare actual acquisition chains with recipient-visible declared groups, never giving the audit to a listener. Record missing/visible links without claiming verified origins, exact-copy access, selected/injected relays and misattribution separately. Verify matched listener pairs' delivered messages, hidden-origin pairs' identical local inputs/behavior and attribution-only pairs' unchanged private assignments/propositions/actual roots. Measure support, candidates, selected speech, executed ballots and verdicts separately, retaining absent effects and wrong outcomes. Count delivery copies, retained messages and serialized attribution/lineage values as storage proxies; do not infer RAM/runtime overhead. Document genuine corrections as deferred, not silently accepted. Findings and engineering validation live separately in experiments/004/results.md and validation.md.

For 005, preregister explicit revision targets, own-message ownership, observation supersession, cost/intent policies, branch/group conflict and missing-reference handling before implementation/primary evaluation. Preserve 001–004 engines/tests/evidence. Run fmt, warnings-denied Clippy and the full suite before `cargo run --bin experiment005 -- evaluate evidence/experiment-005.json`; freeze with create-new only. Add frozen 005 regression afterward and rerun relevant gates; never overwrite prior artifacts.

Compare Frozen004 and Revision with shared 005 local observation inputs; record whether delivered messages match or voluntary forwarding differs. Separately measure private mismatch, selected/withheld revision, valid recipient interpretation, candidate/support, executed ballot and verdict. Recovery requires a prior wrong candidate and final correct candidate; uncertainty and a different wrong candidate remain distinct. Record all changed config fields in broader mechanism pairs. Keep equal-visible-input hidden-private/intent controls and selected-versus-injected comparisons. Preserve originals, observations and mental snapshots; capture injection resolver inputs too. Report missing/contested/unverifiable standing without using audit to reconstruct payloads. Scientific results and engineering validation are experiments/005/results.md and validation.md; later hypotheses require new preregistration and evidence.
