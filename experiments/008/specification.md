## Questions and falsification

H1: local unresolved/competing support and resources can change selected investigation. Falsified if the built-in selective policy ignores these inputs in matched diagnostic states. H2: legally acquired evidence can change beliefs, selected communication and executed ballots. Falsified if no declared accurate-information diagnostic changes those links. H3: misleading investigation can worsen judgment. Falsified if all adverse diagnostics have no worse factual decisions. H4: budgets can alter timing/frequency and conserve a later opportunity; falsified if exhaustion/conservation controls have identical choices despite available versus exhausted tokens. H5: identical local inputs imply identical actions despite hidden content/roots/truth changes. H6: received historical credibility can change investigation in otherwise identical present circumstances; not a claim of reliable reputation. H7: visible dependence can avoid extra contributions, while hidden dependence stays inaccessible. H8: usefulness depends on source quality/cost/history; no universal superiority threshold. Hypotheses are separate; retain adverse/null results and report unsupported ones.

## Latent environmental artifacts and legal access

Artifacts are initialized before policy selection. Each has a stable incident-local source ID, public descriptor, allowed inspector subset, candidate or missing result, and observer-only actual causal root. A physical trace's root is that artifact; a derived record's root is an initial observation identified by its owner. Derived content copies that observation at initialization, not after inspection. An inaccurate or absent original can yield an inaccurate/missing derived artifact. Visible dependence discloses the named observation source; hidden dependence omits it. Labels never reveal reliability, accuracy or a fault flag. Availability is public/legal access; content, generation details and actual roots are absent from the catalog.

InvestigationView contains ID, episode, current belief, unweighted belief, own received messages, own credit summaries, public accessible catalog, balance, opportunity-open flag, already-used flag, local action cost and public episodes remaining. Inspect(source ID) and Decline are typed actions. A replaceable policy receives this view only. Resolver independently validates phase/opportunity/use/source/access/budget. A successful Finding contains source ID, candidate or missing, disclosed source relationship, and episode/observer acquisition reference. It contains no objective correctness, actual roots, fault source or audit handle. FindingDelivery records chosen-versus-controller origin, recipient, input/output belief and resource consequence with observer labels separately. Two inspectors of one artifact create two acquisitions but one causal origin. Controller injections use the same finding shape and interpretation, cost zero, explicit Intervention origin, bounded legal recipient/source access and separate logs; they are never selected investigation.

## Policies fixed before evaluation

All choose the first accessible source ID deterministically, except SeededRandom, which uses an independent SplitMix64 stream seeded by config seed and observer ID. NeverInvestigate declines. AlwaysInvestigate inspects whenever legal and budget remains. ConflictDriven inspects when the local candidate is unknown or two or more candidates have positive support. These are transparent heuristics, not learned purpose.

CostSensitive uses usefulness U=3 when candidate unknown, otherwise 2 if competing support or margin<=1, otherwise 0. Declared cost C=local configured action cost plus 1 when only one token remains. Inspect iff U>C (tie declines), otherwise conserve. CredibilityAware adds 2 to U if any currently received original speaker has negative local credit, or credibility-weighted candidate differs from unweighted candidate; then applies the same strict gate. It does not see objective speaker accuracy and may unnecessarily inspect a now-correct low-credit source or fail to investigate trusted misinformation. Primary cost 1; high-cost diagnostic 3. SeededRandom inspects on one policy-local random bit, chooses an accessible source by the next draw; no inspection if unavailable/exhausted. Choice audit captures U,C, warning and reason alongside the input, without rerunning policies later.

## Evidence interpretation and communication

Keep 006 credit update/weight formula and 005 revision/provenance rules unchanged. Base initial private observation retains weight 2 (briefing 6 if legally provided). New findings do not supersede this anchor. Acquired nonmissing artifact evidence contributes weight 2; a public artifact report contributes 1. Ordinary testimony keeps max(0, 1+local source score), bounded 0-3; neutral listener uses weight 1. A visible observation parent maps to that speaker's perceived group; otherwise the artifact source ID defines a perceived artifact group. Repeated acquisitions/reports of one source, including two investigators and exact forwarding, contribute at most one maximum weight per group. Candidate disagreement within a perceived group contests it and gives zero. Known derived evidence matching already-counted testimony can replace its weight by max(existing, 2), never add a new independent group; report the difference explicitly, not an independence discovery. Hidden dependent evidence appears as a different artifact group because the actual root is unavailable. Missing findings add zero. Unique positive maximum selects candidate; ties are uncertainty. All inputs/assessments are captured at execution.

The evidence listener starts from unchanged 005 branch interpretation/006 testimony weights. Explicit reports of a finding remap that original message group's identity to its reported artifact or disclosed observation source, retaining the group through revisions. A speaker's own public report adds no new own support. A source-group echo is not independent evidence. A root group's explicit revisions/retractions continue using 005 standing; finding-derived support is not an automatic latest-observation replacement.

Communication remains voluntary. Default reuses 005 Sincere for ordinary current-belief assertion/revision. A minimal ShareFinding policy offers an acquired result on round 2, as an original assertion if no prior assertion or an own revision otherwise; missing results may yield uncertainty/retraction. It can stay silent if no finding. Share mode does not assert privileged accuracy or force a verdict. Silent mode preserves private findings; RelayFinding may forward an actually received exact finding report with a visible reference and unchanged artifact identity. Resolver requires an own delivered finding or exact received report for an explicit finding payload, verifies recipients and ownership, and records environmental ancestry separately from 005 message lineage. Inference-based ordinary conclusions may use private findings without claiming firsthand original observation. Observer lineage records actual roots for acquired/report support; these are never ordinary dialogue fields. Pure artifact reports are excluded from 006 speaker-accuracy ingestion so investigation does not manufacture a new independent witness reputation. Existing source claims remain graded by the unchanged historical rule.
