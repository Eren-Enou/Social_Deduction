## Source and cost model

At most four source objects per incident, arbitrary unique u8 IDs, stable semantic method keys independent of source display order/ID, bounded descriptions. Public catalog contains only accessible sources, actual price 1/2/3, category Partial/Physical/Specialized/Derived, declared accuracy and missingness percentages, candidate coverage and visible observation parent. Quality claims originate from declared instrument specifications, not observer correctness. Described coverage is an assumption about possible candidate results, not a guarantee; actual results may violate it. No zero-cost sources in this version. Initial budgets 0-9 (primary diagnostics 3, generated 1-6), no replenishment/transfers/refunds. Resolver subtracts the selected actual price even for missing/false findings; rejected selections cost nothing and consume the opportunity without fallback. Initial=spent+remaining independently for each individual.

Latent candidate and actual root live in observer Source only and are frozen before treatment. Physical roots identify source objects; derived records copy an original observation. Roots and current accuracy never enter pre-access or delivered local views. Source/public identity is incident-local; acquisitions namespace episode/observer/local index. Visible known observation dependence retains 008 max-weight grouping; actual hidden dependence is not discovered. Same artifact inspected/reported twice does not multiply independent support.

## Selection model fixed before implementation

Seven replaceable policies: NeverInvestigate, FirstAccessible, SeededRandomTarget, CheapestAvailable, ConflictDrivenTarget, InformationValueHeuristic, BudgetAwareTarget. RandomTarget always chooses a legal affordable target if any, using own persistent SplitMix64 stream seeded session XOR(0x9009+observer); it does not randomly decide whether to inspect. FirstAccessible preserves configured catalog order. Other ties prefer lower price then lexicographic stable method key; no source ID or display order tie-break. Semantic keys name instrument instances, not inferred quality.

Capture the entire own EvidenceView and current assessment, public catalog, own balance/stage/use and public remaining incidents. For each source enumerate its publicly described candidate outcomes by adding a hypothetical weight-2 finding to the identical captured local evidence and running unchanged008 interpretation. Uniform possible-result prior over described candidate coverage is an explicit forecasting assumption; support scores are not probabilities. Missing leaves the local state unchanged. Declared accuracy scales the forecast usefulness, while errors are conservatively assigned zero useful change rather than an oracle-derived result. V in 0-1000 = fraction of enumerated outcomes changing the candidate times declared accuracy fraction times nonmissing fraction, truncated integer arithmetic. Preserve each hypothetical candidate and resulting belief. If a visible observation parent already supplies nonmissing local evidence, treat the expected result as that locally known candidate; repeated confirmation normally has V0 and cannot be estimated as novel independent support. Unknown ancestry stays unknown.

Relevance R in 0-1000 = fraction of current positive-support candidates covered by the source times declared accuracy times nonmissingness. If there is no support, all six candidates define the reference set. ConflictDriven selects maximum R only with unknown candidate or at least two positive candidates; descriptions unable to discriminate yield equal R and documented ties, not invented relevance. Cheapest selects minimum actual price. InformationValue chooses maximum V-100*price, only if strictly positive. BudgetAware chooses maximum V-150*price-150*reservation, only if positive, where reservation=1 when later incidents remain and post-cost balance is below min(remaining incidents,2). Both can decline all affordable targets. Never declines. All considered sources, affordability, overlap, V/R, hypothetical outputs, scores, costs and tie rationale are recorded at selection time. These are transparent heuristics, not optimal or calibrated information economics.

## Pre-evaluation engineering clarifications

Public provenance additionally distinguishes Unknown, Observation(parent) and explicitly disclosed SeparateAcquisition. Separate-acquisition disclosures are controlled legitimate method metadata and validated against separate latent acquisition identity; physical methods with even semantic instance index disclose it, odd instances remain unknown, derived records never disclose separation. This is independent of price/accuracy and adds no random draws. Interpretation retains008 identities and cannot infer undisclosed roots. Lexicographic method-key ties are an explicit semantic-instance preference, not universal invariance to renaming those semantic labels.

Source identity permutation uses a seed with the bijectively mapped actor because005 stores the actor as a seed function rather than an overridable field; observations, coverage, IDs and speaking roles are mapped together. Original preregistration is preserved. StrongInitialBelief has unopposed private support2 with silent communication, which can still tie a hypothetical rival finding2; it tests apparently settled belief, not mathematical dominance. A separate engineering dominant-briefing control verifies conservation under support6. ResourceScarcity tests budget reservation without changing this forecast limitation: the information-value policy may still spend because decision change is not synonymous with improvement. No policy formula, threshold or held-out generator distribution was tuned.

Normal proposals are recorded once; forced decisions additionally preserve the replaced proposal. Counterfactual ordinary selectors receive later explicit decline interventions to restrict their choices to episode0, while alternative policies naturally decline then. Their delivered information/action availability outside episode0 matches; audit intervention labels differ. Baselines also enumerate possible outcomes for common audit measurement, so hypothetical-assessment counts are not incremental performance benchmarks for complicated policies.

Pre-primary fixture review correction: EqualSources/CostDifference match the optional separate-acquisition disclosure as well as category/coverage/quality. A fourth physical source uses Physical category until generation actually copies an observation and sets Derived. These corrections precede held-out execution and align metadata with the declared controls; the interrupted earlier full-suite attempt is not a completed gate.
